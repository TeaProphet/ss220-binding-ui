# SS220 Binding

Локальный веб-редактор биндов Space Station 14. React, Vite, Express и YAML. Требуется Node.js 22.12+ (или 24+).

## Запуск

```powershell
npm install
npm run dev
```

Откройте http://127.0.0.1:3141. Для готовой сборки: `npm run build`, затем `npm start`.

Для обычного запуска используйте ярлык **SS220 Binding** на рабочем столе или найдите его через поиск в меню «Пуск». Также доступен файл `Launch Binding Deck.cmd` в корне проекта. Он запускает production-сборку, ждёт доступности локального API и открывает редактор в браузере. Если сервер уже запущен, второй экземпляр не создаётся.

Для остановки используйте ярлык **Stop SS220 Binding** или файл `Stop Binding Deck.cmd`. Он завершает только сервер SS220 Binding на порту `3141`.

Редактор читает `%APPDATA%\Space Station 14\data\keybinds.yml`. Если файла нет, показывает стандартные назначения. Файл создаётся только по кнопке «Сохранить в игру». Сохраняйте при закрытой игре: игра также записывает этот файл. После сохранения запустите игру заново.

Перед перезаписью создаётся резервная копия рядом с файлом: `keybinds.yml.<дата>.<id>.bak`. Для восстановления закройте игру и скопируйте нужную резервную копию в `keybinds.yml`. Если файл изменился с момента открытия редактора, сохранение блокируется: экспортируйте свой вариант и перечитайте файл.

## Возможности

- Все стандартные и пользовательские назначения, поиск и категории.
- Добавление, редактирование, удаление, отмена изменений и сброс действия к стандартным назначениям.
- Захват физических клавиш независимо от раскладки, Ctrl/Shift/Alt, numpad и кнопок мыши. Одиночный модификатор определяется при отпускании. Escape можно назначить.
- Ручной выбор клавиш и до трёх модификаторов для сочетаний, перехватываемых ОС или браузером.
- Команды `say`, `me`, `whisper`, игровые действия State и Toggle.
- Просмотр совпадающих сочетаний; они не обязательно конфликтуют из-за разных контекстов игры.
- Импорт, экспорт, предпросмотр YAML; сохранение неизвестных полей, `leaveEmpty` и дополнительных параметров. Форматирование и комментарии YAML при сохранении нормализуются.

Базовый набор включён из официального Wizard’s Den. Форки могут добавлять или менять действия. Для точного набора своего сервера импортируйте его `Resources/keybinds.yml` кнопкой под таблицей. Этот базовый набор действует до перезагрузки страницы; пользовательские изменения сохраняются отдельно. Приложение не извлекает ресурсы сервера из кеша лаунчера. В файл игры записываются только пользовательские настройки, остальные игра берёт из своих ресурсов.

Для другого пути или тестирования:

```powershell
$env:SS14_KEYBINDS_PATH = 'C:\path\keybinds.yml'
$env:PORT = '3141'
npm run dev
```

Сервер слушает только `127.0.0.1`, проверяет Host/Origin и токен записи. Нет облачного хранения. Изменения редактора до сохранения хранятся в памяти вкладки. Пресеты персонажей сохраняются в `binding-deck-presets.json`, а общий слой для всех персонажей — в `binding-deck-global.json` рядом с `keybinds.yml`. При применении слои объединяются по порядку: общий → персонаж → роль.

## Проверки

`npm test` — YAML, объединение назначений, захват клавиш, резервные копии и конкурентная запись.

`npm run build` и `npm run test:e2e` — браузерные проверки через установленный Microsoft Edge. E2E использует отдельный файл в `test-results`, не настройки игры.
